- [x] Integrate the compact frame, numeric typography, panel/status chrome, control edges/focus and plot roles without changing layout or navigation contracts.

- [x] Capture native before/after evidence, all six themes and laptop/HD/QHD/4K/narrow plus scaled conditions.
- [x] Run the locked fast, full offline and applicable actual-backend gates. Keep failed attempts and skip reasons.
- [x] Obtain independent visual and technical dispositions after repairs; stop for the bounded owner review.
- [x] Owner accepted PR 1, not a release or PR 2.
